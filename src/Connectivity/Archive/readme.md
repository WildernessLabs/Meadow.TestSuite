# Test Archives

The files in the directory are archived as they are not used.  The code has been preserved in case it becomes useful at a future time.

## BluetoothTestRunner

This is a Rust application designed to exercise the Bluetooth server functionally running on a Meadow device.  The code uses the Blurz library and has been tested on running on a Raspberry Pi.

This application has been replaced by the BluetoothClient test application which is written in Python and has been tested on a Raspberry Pi and Mac computer.
